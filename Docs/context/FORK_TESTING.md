# Fork: testing

Job: test. What done means. Not a new design.

## Open

- The beat evidence for the thing under test
- The prove bar named for that beat
- `Docs/qa/HUMAN_TUTORIAL.md` only if it is committed and `Content/Python/human_tutorial.py --check` exits 0

## Leave closed

New art. New locks. The asset track. Do not treat a clean log as done.

## Track

`Docs/context/PROVE_TASKS.md`. One named prove. One change, one run, then stop, when the task is still unknown. Do not tick sign-off.

## Pass

The human says the bar is met. The agent does not tick sign-off. Until the tutorial exists, name the next manual step in one line.
