# Level and route rules

Open this file when the task touches a route sentence, a placeable, a merge, or the level. These are the old door rules 6–9. They are not a session-start read.

1. A route line about movement or space names the axis, the distance, and what is past the edge, and matches the GDD.
2. A placeable actor needs a scene root and a keep-transform check.
3. Docs and Source merge after the tests pass: Lead's standing merge permission (`AGENTS.md` § Locks). A `.umap` or `.uasset` commit still waits for Lead's yes (solo: Luke's yes). When Luke has said to run a recorded queue, that is the yes for the level items it names (`Docs/context/SESSION_START.md`).
4. A route or GDD sentence changes only after Lead says yes to that exact sentence.
5. Before placing or lighting a test scene, open `Docs/context/SCENE_SETUP.md` and that map’s `Docs/level/<Map>_CONTEXT.md`. The metrics file is the coordinate list. The context file is the measured floor, who belongs in the scene, and the setup practices. A first measured failure is written into `SCENE_SETUP.md` before the next scene.
