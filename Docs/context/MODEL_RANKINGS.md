## Protocol

First task on a feature starts on the bucket **first wave** pick. Later passes cross-reference the remaining models of the same bucket, in listed order, and **agents recommend rather than switch** - the human changes model via /models.

## Legend

Picker labels round AA to one decimal and TB40 to whole percent; this file keeps one decimal everywhere.

- **Vals dissent**: on covered models Vals v2.1 ranks MiMo 53.23 (#20/49) > DeepSeek 51.32 (#26/49) > GLM-5.3-Flash 44.58 (#41/49). The chosen basis is AA.
- **Picker order**: the /models order comes from artificial `releaseDate` keys in `%USERPROFILE%\.config\opencode\opencode.json`; the key is never displayed. Verified 2026-10-17 against opencode v2.0.22: the picker parses each key into a numeric `time.released` (epoch ms - a bare `YYYY-MM-DD` becomes that day 00:00Z) and sorts each provider group by it **descending**, with the display `name` alphabetical as the tie-break. So keep every date inside a bucket **distinct** and descending in the intended cross-reference order; a duplicated date silently reorders that pair by name. This script does not edit that config; re-key by hand or ask the agent after material rating shifts.
