# Art folder

Pictures stay with their place. Process docs stay in this folder. The five states and the five transitions are in `PHASES.md`. The open transition is the Now line at the top of that file.

## Phase and sitting

| File | Job |
|---|---|
| `PHASES.md` | The Now line, the five states, and the five transitions. |
| `SCALE.md` | One look. Vista copies, a dense pocket, one giant. From Concept on. |
| `transitions/CONCEPT.md` | Open context. Industry gate, then HomeWorld. |
| `transitions/CONCEPT_TO_GREYBOX.md` | Closed until Concept is kept. |
| `transitions/GREYBOX_TO_PROTOTYPE.md` | Closed until Greybox is kept. |
| `transitions/PROTOTYPE_TO_POLISH.md` | Closed until the player’s Prototype is kept. |
| `transitions/POLISH_TO_FINAL.md` | Closed until that asset may export. |
| `ASSET_CONTEXT_TASKS.md` | The running list. Critical path, then one card. |
| `STILLS_LIBRARY.md` | Filed pictures and the job of each. |
| `STILL_GENERATION_STANDARD.md` | Model sheets. Front first. Side is 90 degrees. Back is 180. |
| `VISUAL_NOTES_FOR_GENERATION.md` | Paste block and place scripts. |
| `PROTOTYPE_ASSET_BRIEFS.md` | The prompt for one asset. |
| `PROTOTYPE_PIPELINE.md` | Still, then mesh, then Blender, then two looks. |
| `PROTOTYPE_ASSET_TRACK.md` | Play order and pass bars. A box is checked only when that bar is called true. |

Look work opens `Docs/context/ART_ASSET_DOOR.md`. That door reads the task list, then these files only when the sitting generates or meshes.
