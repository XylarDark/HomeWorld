## Normative (3–5)

1. **Wholesome homestead hub.** Floating-island homestead is a **safe hub**. No combat, no aggro, no weapons on the homestead.
2. **Day body ≠ night spirit verbs.** Day/body and night/spirit must **not** share the same verb set. See `Docs/canon/VERBS.md`.
3. **MVP slice only.** One homestead hub + one readable planet-below slice. No extra biomes, beasts, maps, or free-flight sim.
4. **Fun and pillars beat systems.** Prefer the simplest playable test. Art path: Blender library first, then UE5. Phaser only for cheap loop prototypes.
5. **Combat = kill/HP combat is forbidden.** Night **placeholder dream-convert** (heal/recruit, convert not kill) is allowed per `Docs/21_REAP_SOW.md`. Homestead stays non-combat either way.
