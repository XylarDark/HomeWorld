## Normative (5)

A feature that fails two of these waits.

1. **Love is the stakes.** Family is present, and the camp rescue is why the ease exists.
2. **Care replaces killing.** Spirit encounters heal, calm, or convert. There is no kill.
3. **One stroke you can fail.** Encounters are that stroke. A second verb family waits.
4. **Home stays safe.** The homestead is not a combat place.
5. **The place teaches itself.** Terrain, material, silhouette, and light teach the action before UI.

## Retired as the feature gate (2026-09-20)

Kept so older docs still have a reading. They do not judge the next feature.

1. **Wholesome homestead hub.** Floating-island homestead is a **safe hub**. No combat, no aggro, no weapons on the homestead.
2. **Day body ≠ night spirit verbs.** Day/body and night/spirit must **not** share the same verb set. See `Docs/canon/VERBS.md`.
3. **MVP slice only.** One homestead hub + one readable planet-below slice. No extra biomes, beasts, maps, or general-purpose flight sim. The island-to-field glider descent is freely steered.
4. **Fun and pillars beat systems.** Prefer the simplest playable test. Art path: Blender library first, then UE5. Phaser only for cheap loop prototypes.
5. **Combat = kill/HP combat is forbidden.** Night **placeholder dream-convert** (heal/recruit, convert not kill) is allowed per `Docs/21_REAP_SOW.md`. Homestead stays non-combat either way.
