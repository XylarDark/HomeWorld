## Moment-to-moment

Walk / interact / short channel (gather ~1.5–3 s, heal/nurture ~2–4 s, portal ~3–6 s). Readable prompts. Soft fail (full inventory, wrong form, locked shrine) — no void-death loop.

## Session (one day → night → dawn)

1. **Dawn / day body** on homestead — gather/beast/store active; spirit layer off.
2. **Depart** lookout / glider perch → FALLBACK glide → landing circle.
3. **Reap** on planet path (materials, living sites, tame).
4. **Dusk** → spirit at homestead shrine; NightMix → 1; day reap interacts blocked.
5. **Sow / dream** — portal ↔ planet; nurture; placeholder dream-heal/recruit; heal ×3.
6. **Rest / dawn** → body on homestead; NightMix → 0.

## Long-term (MVP)

Persist optional inventory / tame / nurture across dawns. Docs/21 cross-buff special site: day bonus feeds night performance; night bonus feeds day. No skill trees.

## Day loop vs night loop (meet at island)

| | Day / body | Night / spirit |
|---|---|---|
| Where | Homestead walk + planet slice | Homestead first, planet via shrine |
| Core | Reap: gather / collect / claim / tame | Sow: nurture / influence; dream-convert; heal |
| Transit | Glide island → planet (FALLBACK) | Portal A ↔ B only |
| Meet | Homestead hub — form swap at dusk/dawn; store / nurture stage |
