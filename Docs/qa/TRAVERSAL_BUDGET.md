A window's shape decides how it can be tested. A **point-to-point** journey
can weave indefinitely, so island size cannot contradict it and this script
never reports it as failing. A **closed loop** returns to its start, so its
length is bounded by the perimeter - that is the only shape where size and a
window can genuinely contradict each other.

## What this does not establish

- It uses a **straight-line lower bound**. Real routes are longer, so every
  failure reported here is real, and every pass proves nothing.
- It assumes **constant speed on flat ground**. Real traversal is slower
  uphill, at corners, and around obstacles.
- The perimeter is an **ellipse approximation**, not a path.
- It says nothing about whether a walk would feel good. That is a taste gate.
