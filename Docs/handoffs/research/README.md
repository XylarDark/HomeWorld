# Research prompts & EXITs (file protocol)

Canonical **PROMPT_*** and **EXIT_*** markdown files live here. Law: `Docs/handoffs/RESEARCH_PROMPT_CONTRACT.md` (Design and studio lookups).

- Conductor writes `PROMPT_<ID>.md` before posting the **path** in HomeWorld Co.
- Lead returns `EXIT_<ID>.md` (same ID) before Conductor ACCEPT.
- Chat is not the canonical prompt body.
- Open this index only when the task is explicitly research. Then open the one topic file for that body. Append new findings there. Do not open the other topic files.
