# Vision Board

This directory holds **vision, MVP, and world design** for HomeWorld, plus **prompt files** and **encoded key art**. Look law is not restated here.

**Art source of truth:** [Docs/02_ART_BIBLE.md](../Docs/02_ART_BIBLE.md) (updated 2026-09-30). Encoded stills: [KeyArt/](KeyArt/).

---

## Layout

| Subdirectory | Contents |
|---|---|
| **[Core/](Core/)** | Central vision and scope: **VISION.md**, **PROTOTYPE_SCOPE.md**, **STACK_PLAN.md**. |
| **[Prompts/](Prompts/)** | One file per theme for vision-board prompts. |
| **[MVP/](MVP/)** | MVP and delivery checklists. |
| **[Planetoid/](Planetoid/)** | Planetoid and world design. |
| **[Character/](Character/)** | Character creation and UI flow. |
| **[KeyArt/](KeyArt/)** | Base64 stills for the current art lock. Decode locally. Do not treat as a second bible. |
